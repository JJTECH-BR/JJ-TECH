## Sobre a JJTech

A JJTech nasceu para ajudar empresas a crescerem com presença digital forte, soluções eficientes e interfaces modernas. Nossa missão é transformar ideias em experiências digitais que gerem valor, aprimorem processos e fortaleçam a imagem da marca no mercado.

A empresa atua com foco em:

- sites profissionais;
- landing pages;
- lojas virtuais;
- sistemas web personalizados;
- soluções digitais para pequenas empresas.

Com uma abordagem prática, clara e estratégica, a JJTech combina desenvolvimento, design e atendimento para entregar resultados reais. Nossa equipe possui conhecimentos sólidos na área de tecnologia e está preparada para criar soluções que atendam às demandas do mercado com qualidade, organização e foco em desempenho.

## Como executar localmente

1. Clone este repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

Opcionalmente, você pode usar o Live Server no VS Code para visualizar o site em ambiente de desenvolvimento com atualização automática.

## Como personalizar

Para ajustar o projeto para outra marca ou cliente, basta editar:

- textos e descrições em `index.html`;
- estilos e paleta em `style.css`;
- comportamento interativo em `script.js`.
